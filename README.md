# Personal Portfolio

A responsive personal portfolio website for showcasing my projects, technical
skills, experience, and contact information.

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js 18 or later
- npm

### Installation

```bash
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

### Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Project Highlights

- Responsive layout for desktop and mobile screens
- Project showcase
- Skills and experience overview
- Contact information
